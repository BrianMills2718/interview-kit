# interview-kit

Best-practice notes for building agentic AI solutions with an AI coding assistant: working
rules, short skill guides, and a tested LangGraph agent template. Made to be pulled into a fresh
hosted environment in one command and handed to whatever assistant is there.

## Pull it in

```bash
git clone --depth 1 https://github.com/BrianMills2718/interview-kit kit
# no git:
curl -sL https://github.com/BrianMills2718/interview-kit/archive/refs/heads/main.tar.gz | tar xz
```

No internet in the environment: open
https://raw.githubusercontent.com/BrianMills2718/interview-kit/main/KIT.md in another tab and
paste it into a `KIT.md` file. It is every rule and skill in one file.

## Use it

Attach `AGENTS.md` (or `KIT.md`) as context in the assistant, then start with:

> Read AGENTS.md and follow it for this session. First, restate the task and propose a plan.

## What is here

| File | Use it when |
|---|---|
| `AGENTS.md` | always: how the assistant should work (plan, small steps, run, test, explain) |
| `skills/langgraph-agent.md` | building a tool-calling agent or multi-step graph |
| `skills/evaluate-agent.md` | testing an agent offline and evaluating it on known cases |
| `skills/explain-your-work.md` | writing the README and code explanations |
| `examples/agent_template.py` | a runnable agent to copy (`pytest -v` runs its offline tests) |
| `KIT.md` | generated by `./build_kit.sh`: all of the above notes in one file |

## Check it

```bash
uv sync && uv run pytest -v      # 3 passed
./build_kit.sh                   # rebuild KIT.md after editing any note
```
