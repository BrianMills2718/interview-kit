# interview-kit wiki

Start here if you maintain or extend the kit. Users of the kit only need the
[README](../README.md).

## What this repo does

A small, public kit that brings a working method (plan first, small checked steps, tests that
could fail, a review pass, a clear explanation) into a timed take-home coding test held in a
hosted browser IDE, where only the IDE's own AI chat may be used. It is pulled in with one
`git clone`, or pasted as one file (`KIT.md`) when there is no internet. The same files install
as a Claude Code plugin.

## Decisions

Each says what would show it was wrong.

1. **Claude Code plugin layout** (`skills/<name>/SKILL.md`, `agents/*.md`, `.claude-plugin/`):
   one set of files serves the hosted IDE (read as markdown) and Claude Code (loaded natively).
   Wrong if a hosted IDE's assistant cannot use files in this layout and needs a different one.
2. **Enforcement is a script the user runs** (`check.sh`, optionally a git pre-commit hook or a
   CoderPad run target), because a hosted IDE has no hooks we control. Wrong if a test run shows
   the script cannot run there (it did run in the sandbox on 2026-10-10).
3. **One generated file** (`KIT.md`) as a fallback for an IDE with no terminal or no internet.
   Not a size limit on the kit: the IDE's terminal has internet, so the kit is cloned and its
   files read directly. Wrong if a test environment turns out to have no internet; then cut
   `KIT.md` to the rules and plan template.
4. **Light commit rule in this repo** (`.aes/commit_rule.yaml`: plan tag enforced, plan-adoption
   verdict logged, not blocking), at the owner's request (2026-10-10).
   Most refusals that led to it came from misusing quick-adopt
   (company-planning issue 118).
   Wrong if a commit here lands without a real plan file; then set `plan_adoption: enforce`.
5. **Public repo, no private data**: no company names, interview details or personal data.
   "Company names" means any employer the kit is used for and any company's interview
   practices; the tools the kit runs on (the CoderPad IDE, the `openai` and `anthropic`
   provider packages, GitHub hosting) are named because the instructions need them. Wrong if
   a named tool, together with the repo, would tell a reader which employer or which interview
   it was built for; then describe the IDE generically.
6. **Multi-agent = specialists wrapped as tools**, not the `langgraph-supervisor` add-on: the
   supervisor is the same agent loop as the template, needs no extra package, and is testable
   with the same fake model. Wrong if a task needs agents handing control to each other
   mid-conversation (a swarm or handoff), which this shape does not express.
7. **MCP examples use the official `mcp` 2.x SDK** (`MCPServer`, in-memory `Client` for tests);
   A2A and `langchain-mcp-adapters` are described but not shipped as code, because nothing here
   tests them. Wrong if a task needs an MCP server consumed by LangGraph: then add and test an
   adapter example.
8. **The planning method is copied in, adapted, not linked** (`method/`): notes adapted from the
   owner's own planning, architecture-model and diagram-guidance repositories, with everything
   that needs a team (claims, worktrees, coordination) left out. The `aes` CLI is installed
   from its own repository at a pinned revision (`method/install_aes.sh`); it makes no AI
   calls. Copying keeps the kit readable in one clone. Wrong if a note here and its source
   disagree on a rule that matters in a test; then re-copy from the source.
9. **`KIT.md` bundles every note, the method included, with no line cap** (owner, 2026-10-11:
   "it doesnt just have to be pastable"). Pasting also shows in the IDE's playback, so cloning is
   the main route and `KIT.md` is the fallback. `tests/test_model.py` fails if a note is left out.
   Wrong if an IDE's chat refuses or truncates a file this size when attached; then attach the
   notes one by one instead of trimming the kit.
10. **Adapted text keeps its source and licence**: superpowers and awesome-copilot passages (MIT)
   are adapted with attribution in the note; interview-practice pages and 12-factor-agents are
   paraphrased, not copied, and no employer is named. Wrong if a note quotes such a page.
