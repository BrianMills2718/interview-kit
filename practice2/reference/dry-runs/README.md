# Diagrams from the practice dry runs

Each run wrote a one-page system model (`MODEL.md`) with six diagrams; GitHub draws them.
These are records of what a fresh agent produced, kept as written (they predate the
"**Answer:**" line the template now asks for). Like the rest of `reference/`, a practice run
deletes this folder.

| Run | Problem | Model | Notes |
|---|---|---|---|

| practice, sample run | order support | [../../../practice/reference/sample-run/docs/MODEL.md](../../../practice/reference/sample-run/docs/MODEL.md) | kept up to date with the template |

The six diagrams in each: 1 context, 2 building blocks, 3 main sequence, 4 rule order,
5 states, 6 data contracts. How each run went: `docs/plans/kit-v3-practice2.check.txt`.
