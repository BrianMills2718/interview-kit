# Diagrams from the practice dry runs

Each run wrote a one-page system model (`MODEL.md`) with six diagrams; GitHub draws them.
These are records of what a fresh agent produced, kept as written: they use the earlier
six-diagram format (and predate the "**Answer:**" line), not the current PRD / MODEL / ADR
package in `templates/`. Like the rest of `reference/`, a practice run
deletes this folder.

| Run | Problem | Model | Notes |
|---|---|---|---|
| practice2, run 1 (2026-10-11) | security triage | [run1/MODEL.md](run1/MODEL.md) | the agent had read the first problem's answer |
| practice2, run 2 (2026-10-11) | security triage | [run2/MODEL.md](run2/MODEL.md) | clean run, both answers removed |
| practice, sample run | order support | [../../../practice/reference/sample-run/docs/MODEL.md](../../../practice/reference/sample-run/docs/MODEL.md) | current format: domain model, state machine, sequence, tests from the model |

The six diagrams in each run: 1 context, 2 building blocks, 3 main sequence, 4 rule order,
5 states, 6 data contracts. How each run went: `docs/plans/kit-v3-practice2.check.txt`.
